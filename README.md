# Next Codeck

AI Presentation Design System by Next Interativa.

Next Codeck is designed to help create editable PowerPoint presentations using a controlled presentation system: an approved master template, slide-specific rules, approved icons and approved photography.

## Core principles

1. The approved master template is the visual source of truth.
2. Slide layouts must be selected according to the approved slide rules.
3. Only approved icons may be used.
4. Only approved photography may be used.
5. New visual assets must not be introduced without explicit authorization.
6. Presentations should remain editable in PowerPoint whenever possible.
7. Every generated presentation should pass the Next Codeck quality check before delivery.

## Repository structure

- `core/` — agent instructions and presentation intelligence
- `template/` — master PowerPoint template
- `rules/` — slide usage rules and supporting data
- `assets/icons/` — approved icon library
- `assets/photos/` — approved photography library
- `examples/` — approved examples and references
