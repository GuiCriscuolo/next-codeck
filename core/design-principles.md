# Next Codeck — Design System

## Format
- 16:9 widescreen.
- Master dimensions: 13.333 × 7.5 inches.
- 60 presentation slides and 54 named PowerPoint layouts.
- PowerPoint layout names are canonical implementation references.

## Typography
The PowerPoint theme uses **Avenir Next LT Pro** for both major and minor theme fonts.
Do not replace it unless a project-specific approved exception exists.

## Core color system

The visual language is anchored in dark navy, white and deep blue, with cyan as an accent.

## Recurring visual language
- Dark navy for major section bands, dividers and footer elements.
- White as the dominant content background.
- Dark navy titles on white; white titles on navy.
- Large editorial image crops with rounded/curved treatment.
- Circular navy icon containers for supporting information.
- Codeck logo as a recurring brand anchor.
- Recurring footer signature: “YOUR PRESENTATION DNA SCALED BY IA | © 2026 Codeck”.
- Large dark-navy rounded blocks for section/title areas.
- Strong title scale, generous whitespace and restrained supporting elements.

## Composition
1. Preserve the master grid and alignment.
2. Keep recurring footer/brand elements consistent.
3. Use whitespace as an active design element.
4. Maintain consistent spacing between repeated cards, icons and text blocks.
5. Keep image and text areas balanced.
6. Use repeated components consistently within a slide.
7. Avoid unnecessary decoration.

## Image treatment
The master demonstrates large vertical image areas, rounded image corners, image/text split compositions and dominant imagery for opening/divider content. Choose photography based on message and approved assets.

## Icon treatment
The master repeatedly uses icons inside dark-blue circular containers.
- Prefer approved icons from `assets/icons/`.
- Keep icon treatment consistent within a slide.
- Do not mix unrelated icon styles.
- Do not use icons as decoration when they do not clarify content.

## Data visualization
Use dedicated chart, table and infographic layouts whenever their communication purpose matches the content. Do not force quantitative information into generic text layouts when an approved data layout exists.

## Scope
This document describes rules directly observable in the approved master and does not invent additional brand rules.
