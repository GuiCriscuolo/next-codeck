# Next Codeck — Asset Selection Rules

## Objective
Choose approved assets that strengthen the slide message without creating visual noise or breaking the master layout.

## Selection sequence
1. Read the slide's communication purpose.
2. Identify the semantic concept needing visual support.
3. Search the asset catalog using concept keywords.
4. Filter by asset type required by the master layout.
5. Prefer an asset whose composition supports the intended crop.
6. Avoid duplicate assets across adjacent slides.
7. Confirm that the asset exists under \`assets/\`.
8. If no suitable approved asset exists, flag the gap.

## Icons
Use icons primarily when the selected master expects 2–8 conceptual highlights or feature cards. Do not use an icon merely to decorate a slide.

## Photos
Use photography when the selected master includes a meaningful image area, the photo supports the narrative, the crop works, and the photo does not compete with the title or data.

## Semantic confidence
Filename keywords are evidence, not a guarantee of visual meaning.
- HIGH: filename directly describes the concept.
- MEDIUM: filename provides a useful but broad clue.
- LOW: filename is ambiguous or contains only an author/ID.

Do not describe a photo in detail unless the image itself has been inspected.

## Output
When selecting assets, record:
- asset path
- reason for selection
- confidence
- intended crop / placement
