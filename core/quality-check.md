# Next Codeck — Quality Check

## Narrative
- [ ] Audience is clear.
- [ ] Presentation objective is clear.
- [ ] Every slide has a defined communication purpose.
- [ ] Sequence is logical.
- [ ] No slide exists only because information was available.

## Slide-function compliance
- [ ] Every slide maps to an approved Codeck function.
- [ ] Selected layout matches the function.
- [ ] Historical Timeline is used only for chronological history.
- [ ] Process Roadmap is used for processes, methodologies, journeys or operational sequences.
- [ ] Product Roadmap is used for future product planning by period.
- [ ] Flexible Content is used when custom composition is genuinely required.

## Visual system
- [ ] Master template is used.
- [ ] Avenir Next LT Pro theme is preserved.
- [ ] Approved color system is respected.
- [ ] Alignment and spacing are consistent.
- [ ] Footer/brand system is preserved.
- [ ] No unnecessary decorative elements were introduced.

## Assets
- [ ] Icons come from the approved icon library.
- [ ] Photography comes from the approved photography library.
- [ ] No unauthorized logos or visual assets were introduced.
- [ ] Images are not distorted.
- [ ] Cropping supports the composition.

## Content
- [ ] Titles are concise.
- [ ] Text is readable at presentation scale.
- [ ] Repeated content is structured consistently.
- [ ] Charts and tables are legible.
- [ ] Data is not visually misleading.

## PowerPoint quality
- [ ] Text remains editable.
- [ ] Shapes remain editable.
- [ ] Tables/charts remain editable when appropriate.
- [ ] No content is clipped.
- [ ] No objects overlap unintentionally.
- [ ] Images maintain correct proportions.

## Final gate
A presentation is ready only when it is both **communication-effective** and **Codeck-system compliant**.
