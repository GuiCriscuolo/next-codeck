# Next Codeck — Storytelling Framework

## Objective

Help turn source content into a clear presentation narrative before applying visual design.

## Default process

1. Identify the audience.
2. Identify the presentation objective.
3. Identify the decision, action or takeaway expected from the audience.
4. Organize the information into a logical narrative.
5. Define the role of each slide.
6. Match each slide to an approved layout.
7. Apply visual hierarchy without changing the approved design system.

## Principle

A slide should have a clear communication purpose. Design should support the message, not compete with it.
