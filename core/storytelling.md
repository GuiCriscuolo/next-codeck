# Next Codeck — Storytelling Framework

Next Codeck separates **storytelling decisions** from **visual execution**.

## 1. Define the objective
Identify:
- Audience
- Presentation objective
- Desired audience action or decision
- Main takeaway

## 2. Classify the content
Classify the slide as opening, navigation, section transition, concept explanation, highlights, features, people, comparison, recommendations, quantitative data, history, process/methodology, product planning, structured data, testimonial/quote, organizational structure, KPI/demographic information, or closing/CTA.

## 3. Select the slide function
Select the canonical function from `rules/slide-library.md`. The function explains **why the slide exists**, not merely what it looks like.

## 4. Select the master layout
Map the function to the corresponding PowerPoint master layout. Do not create a new layout when an approved layout already serves the purpose.

## 5. Reduce the message
Identify:
- One primary message
- Supporting evidence
- Optional secondary details

Remove information that does not contribute to the slide's communication purpose.

## 6. Apply hierarchy
1. Main message
2. Evidence / supporting point
3. Context
4. Detail

## Narrative principle
A presentation should progress logically from context to understanding to evidence to implication/action. Do not force every presentation into a rigid formula.

## Layout principle
Select the layout **after** understanding the communication purpose. Never select a layout simply because it has enough placeholders.
