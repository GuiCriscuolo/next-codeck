# Next Codeck — Visual Slide Catalog

The visual catalog is generated directly from the approved PowerPoint master.

## What the catalog contains

For each of the 60 master slides:

- slide number
- visual preview
- canonical Codeck function
- intended communication purpose
- corresponding master layout
- key usage guidance

## Important

The visual preview is the source of truth for composition. The function/rule description explains the communication purpose.

The catalog should be regenerated whenever the approved master changes.

The current catalog is based on the master provided on 2026-10-05 and the official slide-function mapping supplied for Next Codeck.
